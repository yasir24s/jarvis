JARVIS

Just A Rather Very Intelligent System — a fully local, always-on voice assistant for your Mac.

AI model selection

The installer auto-selects the best AI model for your Mac's RAM. Click Customize on the Installation Type screen to change it.

ModelRAMQualitySize

The 3B model is bundled — no internet needed. Larger models download once during installation.

What gets installed

  • App bundle → /Library/Application Support/JARVIS/ + /Applications/JARVIS.app
  • LaunchAgent — starts JARVIS automatically at login
  • Screensaver — arc-reactor animation for lock screen
  • Python (latest stable) — auto-installed if not already present
  • All Python packages, portaudio, ffmpeg, Ollama, and voice models — bundled
